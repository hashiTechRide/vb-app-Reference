# NPOI 2.7.6 リファレンス（VB.NET / .NET Framework 4.8）

> **検証方法**: GitHub `nissl-lab/npoi` タグ `2.7.6-rc1` のソースを展開し、
> 全シグネチャを実ファイルから抽出して確認。推測・他バージョンからの類推は含まない。
>
> - `Directory.Build.props` → `<VersionPrefix>2.7.6</VersionPrefix>`
> - `main/NPOI.Core.csproj` → `<TargetFrameworks>net472;netstandard2.0;netstandard2.1;net8.0</TargetFrameworks>`
>
> `net472` があるので .NET Framework 4.8 からそのまま利用可。

---

## 0. 【重要】ネット上の情報との差分

Qiita / StackOverflow の NPOI 記事は 2.4〜2.5 系のものが多く、2.7 系では通らないものがあります。
実ソースで確認した相違点は以下。

| 項目 | 古い情報 | 2.7.6 の実際 |
|---|---|---|
| `ISheet.SetColumnWidth` | `(int, int)` | **`(int columnIndex, double width)`** |
| `IFont.FontHeightInPoints` | `short` | **`double`** |
| `IFont.FontHeight` | `short` | **`double`** |
| `ICell.SetCellValue(...)` | `void` | **`ICell` を返す（フルーエント）** |
| 空セル化 | `SetCellType(CellType.Blank)` | **`SetBlank()`** が追加 |
| `XSSFColor(Color)` | `System.Drawing.Color` と誤解されがち | **`SixLabors.ImageSharp.Color`** |
| `XSSFColor(byte())` | 単独 ctor があると誤解されがち | **`(byte[] rgb, IIndexedColorMap colorMap)`** の2引数のみ |
| `XSSFShape` の塗りなし | `SetNoFill(bool)` | **`IsNoFill` プロパティ** |
| `ShapeTypes.Rectangle` | 1 と書かれることがある | **5**。`enum ShapeTypes : int` |
| 角丸四角 | `RoundRectangle` | **`RoundedRectangle`**（26） |

### ★ CellStyle は必ずキャッシュする

XLSX の CellStyle 上限は **約 64,000**。セルごとに `CreateCellStyle()` を
呼ぶとファイルが破損して開けなくなります。

```vb
Private ReadOnly _cache As New Dictionary(Of String, ICellStyle)

Private Function GetStyle(key As String, build As Func(Of ICellStyle)) As ICellStyle
    Dim s As ICellStyle = Nothing
    If _cache.TryGetValue(key, s) Then Return s
    s = build()
    _cache(key) = s
    Return s
End Function
```

`IFont` も同様。`FindFont(...)` で既存フォントを再利用できます。

## 8. 大量データ: SXSSFWorkbook


`rowAccessWindowSize` 行分だけメモリに保持し、それ以外は一時ファイルへ流します。
10万行クラスならこちら。

**制約**: ウィンドウから出た行には `GetRow` でアクセスできません。
`AutoSizeColumn` も基本的に使えません。書き終わったら **`Dispose()`（または

## 9. 定番の落とし穴まとめ

1. **CellStyle をループ内で作らない**（上限 64,000／ファイル破損）
2. **日付は DataFormat を設定しないとシリアル値表示**
3. **`IRow.LastCellNum` は「最終列 + 1」**
4. **`SetColumnWidth` の単位は 1/256 文字**
5. **`AutoSizeColumn` は遅い**（数千行では使用禁止レベル）
6. **`AddMergedRegion` は O(n²)** → 大量なら `Unsafe` 版 + 最後に Validate
7. **`XSSFColor` は SixLabors の Color/Rgb24**
8. **`IsNoFill` はプロパティ**
9. **`CreateDrawingPatriarch()` はシートに一度だけ**
10. **`Resize()` を呼ぶとアンカーの終点が上書きされる**
11. **`FitWidth` は `FitToPage = True` とセット**
12. **SXSSF は一時ファイルを残すので Dispose 必須**
